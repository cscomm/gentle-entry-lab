# 주문 확정·출고 문서 연동

## 구현 내용
- 견적서의 비에이알 사업자 정보를 사업자등록증 기준으로 변경합니다.
  - 상호: 주식회사 비에이알
  - 사업자등록번호: 565-88-02541
  - 대표자: 박금수
  - 사업장 주소: 전라북도 진안군 동향면 동계로 328
  - 업태: 제조업, 도매 및 소매업
  - 종목: 비금속광물 광업, 도소매업, 광물
- 견적 상태에 `주문 확정`과 `출고 완료` 단계를 추가합니다.
- 주문 확정 시 견적 품목·거래처·금액을 그대로 가져와 매출 전표를 한 번만 생성합니다.
- 출고 완료 후 해당 매출 건에서 `거래명세표`를 미리보기·인쇄·PDF 저장할 수 있게 합니다.
- 세금계산서 상태를 `미발행 → 발행 요청 → 발행 완료` 순으로 관리하고 요청일·발행일을 기록합니다.
- 거래명세표에는 비에이알 공급자 정보, 거래처 정보, 품목, 공급가액, 부가세, 합계, 출고일을 표시합니다.

## 화면 흐름
```text
견적 작성 → 발송 완료 → 주문 확정 → 출고 완료
                              ↓
                       매출 전표 자동 생성
                              ↓
                 거래명세표 생성·인쇄/PDF
                              ↓
                  세금계산서 발행 요청 → 완료
```

## 기술 사항
- 기존 견적서·매출 전표 연결을 재사용해 품목 정보를 중복 저장하지 않습니다.
- 매출 전표에 거래명세표 번호, 출고일, 세금계산서 요청일·발행일을 추가합니다.
- 관리자 전용 기능과 기존 비밀번호 보호 방식을 유지합니다.
- 기존 견적·매출 자료와 호환되도록 새 항목은 기본값을 둡니다.
- 완료 후 관리자 화면에서 주문 확정부터 문서 출력·세금계산서 상태 변경까지 직접 검증합니다.
